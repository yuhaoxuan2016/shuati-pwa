# 刷题宝（网页版）

智能题库练习应用 - 导入即刷 - AI 自动解析 - 云端同步

基于 Vue 3 + Vite 6 + PWA 构建，支持 Word 题库导入、顺序/随机练习、错题本、模拟考试。
开发过程中使用了 AI 编程工具辅助开发。
## 功能特性

- **题库管理**：支持从 Word 文档（.docx）导入题目，AI 自动解析题型和答案（AI 解析功能需用户自配 API Key）
- **练习模式**：顺序练习、随机练习、错题重练，支持选项乱序
- **模拟考试**：自定义考试时长、题量、及格线，支持查询码回看
- **错题本**：自动收录错题，支持已掌握标记和自动取消
- **云同步**：基于腾讯云 CloudBase 的双向同步（可选，不配置则纯本地运行）
- **PWA 支持**：可添加到手机主屏幕，离线可用
- **多题型**：单选、多选、判断题，自动识别

## 技术栈

| 层 | 技术 |
|---|------|
| 前端框架 | Vue 3 + TypeScript |
| 构建工具 | Vite 6 |
| 状态管理 | Pinia |
| 路由 | Vue Router 4（hash 模式） |
| 本地存储 | IndexedDB |
| 云同步 | 腾讯云 CloudBase（可选） |
| PWA | vite-plugin-pwa |

```bash
npm run dev

# 构建
npm run build
```

## 云同步配置（可选）

应用默认以纯本地模式运行（数据存 IndexedDB）。如需云同步：

1. 注册[腾讯云 CloudBase](https://cloud.tencent.com/product/tcb) 并创建环境
2. 在应用「设置」页面填入环境 ID（envId）
3. 应用使用匿名登录，每个设备独立身份

构建者也可以通过 `.env` 配置默认云端环境（`VITE_DEFAULT_CLOUD_ENV_ID`，格式见 `.env.example`）。配置后，未手动填写 envId 的访客会自动连接该环境，零配置浏览公共题库与公共考试（只读，可复制为私人副本）；不配置则为纯本地模式。

> 云同步仅同步个人题库和练习进度，公共题库由服务端管理。私人数据（错题/收藏/进度/私人题库）仅本人可见。
